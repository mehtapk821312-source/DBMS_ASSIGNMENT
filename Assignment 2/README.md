##  Assignment Overview

This project focuses on designing a **College Database** using Entity–Relationship (ER) modeling and converting it into relational tables and SQL implementation.

The assignment includes:

- ER diagram design
- Conversion of ER model into relational tables
- SQL CREATE TABLE queries

---

##  Repository Contents

This repository contains the following files:

- `ER_Diagram.png` – ER diagram of the college database
- `college_database.sql` – SQL file with CREATE TABLE statements
- `README.md` – Project documentation

---

##  Database Entities

The main entities used in this database design are:

1. **Department**
2. **Course**
3. **Student**
4. **Faculty**
5. **Enrollment**

These entities are connected through relationships such as one-to-many and many-to-many.
